# دفتر پیگیری تماس‌های ولتن

این پروژه یک وب‌اپ تک‌صفحه‌ای و کاملاً مستقل است. همه HTML، CSS و JavaScript داخل `index.html` هستند؛ نیازی به نصب پکیج، دیتابیس یا سرویس خارجی ندارد.

## انتشار در Vercel
1. فایل `index.html` را در ریشه یک پروژه/پوشه قرار دهید.
2. پوشه را در یک مخزن GitHub قرار دهید و آن را در Vercel از طریق **Add New → Project** وارد کنید؛ یا فایل‌های همین ZIP را با روش دلخواه در پروژه استاتیک Vercel منتشر کنید.
3. نوع پروژه را **Other** انتخاب کنید. دستور Build لازم نیست؛ Output Directory را خالی بگذارید.
4. سایت را باز کنید و روی موبایل به صفحه Home Screen اضافه کنید (اختیاری).

## امکانات
- ثبت یادداشت خودکار با `localStorage` برای هر یک از ۱۵ مخاطب
- علامت «تماس گرفتم» و «رد کرد»، به‌علاوه وضعیت‌های پیگیری، مذاکره و فروش موفق
- افزودن هر مخاطب به چند لیست مستقل، ایجاد و حذف لیست
- فیلتر بر اساس لیست، وضعیت، اولویت و جستجوی نام/شهر/شماره/یادداشت
- لینک تماس `tel:` و منابع اطلاعاتی اولیه
- خروجی JSON پشتیبان و بازیابی آن

## نکته مهم
اطلاعات فقط در **همان مرورگر روی همان دامنه و دستگاه** ذخیره می‌شوند. Vercel اطلاعات را بین دستگاه‌ها همگام‌سازی نمی‌کند. تغییر دامنه، پاک‌کردن داده‌های سایت یا استفاده از حالت ناشناس ممکن است باعث از دست رفتن داده‌های محلی شود. برای انتقال اطلاعات، حتماً از «پشتیبان‌گیری» و «بازیابی» استفاده کنید.

فهرست اولیه شامل **مشتریان بالقوه** است؛ خرید عمده و پذیرش تسویه نقدی هیچ‌یک به‌صورت تلفنی تأیید نشده است.
